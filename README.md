# Assignment 2: Software Testing and Debugging

## Overview

In this assignment, you will apply the software testing and debugging in developped programs. 

You are provided with 5 Python programs across various application domains. Your objectives are:
1. **Develop comprehensive test suites** using `doctest` and `unittest`.
2. **Test complex state and multiple attributes** on object-oriented systems.
3. **Identify and debug software bugs** in the buggy programs.
4. **Configure tests** using testing panel in VSCode to trigger test executions.

---

### Problem 1: Doctest (`problem1.py`)

Add at least **6 comprehensive doctests** in the docstring.

### Problem 2: Unittest with Multiple Attributes (`problem2.py`, `test_problem2.py`)

Implement test methods in `test_problem2.py` for the `BankAccount` class.

### Problem 3: Unittest with Multiple Attributes (`problem3.py`, `test_problem3.py`)

Implement comprehensive test cases in `test_problem3.py` for the `Order` class.

### Problem 4: Unittest (`problem4.py`, `test_problem4.py`)

Implement test cases in `test_problem4.py` for the `MeetingRoom` class.

### Problem 5: Debugging (`problem5.py`, `test_problem5.py`)

The source code (`problem5.py`) and a full test suite (`test_problem5.py`) are already provided. Verify that all tests pass locally.

If you find any bugs in the above five problems, debug them.

---

## Submission Guidelines

1. Commit all your changes to your local Git repository.
2. Ensure that you pass all the tests discovered in VSCode.
3. Fill out `bug_report.md`.

Each problem contributes 20% marks to Assignment 2.
